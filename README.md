# Interactive Solar Storybook — Page 1

Public feedback preview of Page 1 from an interactive children's solar-system storybook.

Open the GitHub Pages site, then try the curtains, Jupiter, wall poster, shelf orrery, drawings, toy rocket, Ari, Dot, lamp, desk globe, and astronomy book. The book opens the story and reads it aloud with separate narrator, Ari, and Dot voice styles when browser speech is available.

This repository is a showcase export. The working project remains outside GitHub.
